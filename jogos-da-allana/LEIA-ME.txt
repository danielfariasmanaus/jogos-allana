JOGOS DA ALLANA — PACOTE PARA PUBLICAÇÃO
=========================================

Este pacote foi preparado para publicação como site estático no GitHub + Netlify.

ARQUIVOS PRINCIPAIS
- index.html          Página principal.
- styles.css          Visual do site.
- script.js           Jogos e interações.
- manifest.webmanifest
- netlify.toml

TESTE NO COMPUTADOR
1. Extraia o ZIP.
2. Abra a pasta "jogos-da-allana".
3. Clique duas vezes em "index.html".
4. O site abrirá no navegador.

PUBLICAÇÃO NO GITHUB
1. Crie um repositório, por exemplo: jogos-da-allana.
2. Envie TODOS os arquivos desta pasta para a raiz do repositório.
3. O arquivo index.html precisa ficar na raiz.

NETLIFY
1. No Netlify, escolha "Add new project" > "Import an existing project".
2. Conecte o GitHub.
3. Escolha o repositório "jogos-da-allana".
4. Branch: main
5. Build command: deixe vazio.
6. Publish directory: .
7. Publique.

ATUALIZAÇÕES FUTURAS
Depois que GitHub e Netlify estiverem conectados, basta atualizar os arquivos do
mesmo repositório. O Netlify publicará a nova versão automaticamente.

OBSERVAÇÃO SOBRE VOZ
A voz usa o recurso de fala do próprio navegador (Speech Synthesis). O navegador
pode pedir uma primeira interação/toque antes de reproduzir sons.
